# MAX30102 脉搏血氧监测示例

本工程使用 STM32F103 的 PB6/PB7 软件 I2C 总线，同时连接 MAX30102 和 SSD1306 OLED。程序轮询 MAX30102 FIFO，完成滤波、心率估算、血氧估算、OLED 显示和简单声光提示。

## 接线

| MAX30102 模块 | STM32F103 |
| --- | --- |
| VIN | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| INT | 可选，当前程序未使用 |

OLED 继续使用原有的 PB6/PB7 接口。MAX30102 的 7 位地址为 `0x57`，OLED 常见地址为 `0x3C`，两者可以挂在同一条总线上。

## 上拉电阻

PB6/PB7 使用“推挽输出、读取时切换输入上拉”的软件 I2C 方式，不强制依赖模块上拉。OLED 模块和 MAX30102 模块如果自带 4.7k 上拉会更稳；如果通信不稳定，可以在 SCL、SDA 上分别增加 4.7k 到 3.3V 的上拉电阻。

## 程序结构

- `SYSTEM/max30102.c`：寄存器读写、FIFO 读取和初始化。
- `SYSTEM/vitals.c`：PPG 缓冲、带通滤波、峰值检测、心率与血氧估算。
- `SYSTEM/oled.c`：OLED 显示和软件 I2C 读写。
- `USER/src/main.c`：采集调度、显示页面、报警灯和主循环。

`SYSTEM/max30100.c/h` 是早期的 MAX30100 版本，当前工程没有编译它，仅保留作对照。

## MAX30102 关键寄存器

- `0x04`：FIFO_WR_PTR
- `0x05`：OVF_COUNTER
- `0x06`：FIFO_RD_PTR
- `0x07`：FIFO_DATA，每个样本 6 字节，顺序为 RED 三个字节、IR 三个字节。
- `0x08`：FIFO_CONFIG，当前使用 `0x0F`，不平均、不循环覆盖，FIFO 深度 32。
- `0x09`：MODE_CONFIG，`0x03` 为 SpO2 模式，`0x40` 为软件复位。
- `0x0A`：SPO2_CONFIG，当前使用 `0x27`，对应 4096 nA 量程、100 Hz、411 us 脉宽。
- `0x0C`：LED1_PA，红光 LED 电流，当前使用 `0x24`。
- `0x0D`：LED2_PA，红外 LED 电流，当前使用 `0x24`。
- `0x10`：PILOT_PA，当前使用 `0x7F`。
- `0xFF`：PART_ID，MAX30102 应返回 `0x15`。

## 显示内容

主页面显示：

```text
SpO2: 98%
BPM : 75
Status: OK
```

底部显示最近 128 个滤波后的 PPG 波形点。状态包括 `NO FINGER`、`ACQUIRING`、`OK` 和 `WEAK`。

## 报警逻辑

- 心率低于 50 bpm 或高于 120 bpm。
- 血氧低于 90%。
- 异常持续 5 秒后，D2 常亮。
- D3 在有效测量时每 500 ms 翻转一次。
- D4 检测到传感器数据时点亮。

这些阈值只是演示值，论文中应根据测试对象和参考设备重新确定。

## 血氧标定

当前代码使用：

```text
R = (AC_red / DC_red) / (AC_ir / DC_ir)
SpO2 = 104 - 17 * R
```

`104` 和 `17` 是演示系数，不是医疗级标定结果。需要用商用血氧仪同步采集数据，对 `R` 和参考血氧值做回归，然后把新系数写入 `SYSTEM/vitals.c` 的估算部分。

## 编译

打开 `USER/keil_project/STM32F1xx_HAL.uvprojx`，工程已经加入 `max30102.c` 和 `vitals.c`。当前命令行编译结果为 0 错误、0 警告。

如果 OLED 显示 `MAX30102 ERROR`，后面的数字表示初始化失败位置。优先检查 3.3V、GND、PB6/PB7、上拉电阻和模块地址。

## 注意

MAX30102 是反射式传感器，手指压力、环境光和遮光结构会明显影响波形。正式测试时应使用不透明指夹或遮光罩，并保持手指压力稳定。本工程用于毕业设计演示和日常监测，不作为医疗诊断设备。
